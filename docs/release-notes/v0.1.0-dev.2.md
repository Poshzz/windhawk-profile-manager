## Fixed

- Support Windhawk locally-added mods whose IDs use the documented `local@`
  prefix (for example
  `local@windows-11-notification-center-styler-fork`). These keys are now
  accepted as safe registry paths instead of aborting profile capture and
  making the environment report 0 installed mods.

## Included

- Mac Blur Glass theme pack (10 mods) and Default Windows reset profile.
- User profiles: create, edit, duplicate, delete, capture, JSON import/export.
- Snapshot-first apply and typed restore with pre-run snapshots, journal recovery,
  automatic rollback, and targeting confirmation.
- `.reg` snapshot import/export plus metadata JSON export.
- Thai/English UI, light/dark/system themes, keyboard/focus/reduced-motion support.
- Settings, snapshot retention, diagnostics, redacted rotating logs, first-run
  onboarding, and recovery finish/archive paths.
- Per-machine NSIS installer for Windows 11 x64; fixed helper directory.

## Warnings and limitations

- No Authenticode signature; SmartScreen and Smart App Control may block the
  installer or app. Use a disposable test machine or SAC-off VM. Do not instruct
  end users to disable Smart App Control on a primary machine.
- Unsigned SHA-256 checksums prove integrity, not publisher identity.
- Windows 11 x64 only; standard `C:\Windows`, `C:\ProgramData`, and
  `C:\Users\<name>\AppData\Local` layout.
- Tray, hotkeys, auto-start, auto-update, and silent scheduling are out of scope.
- A signed stable `v0.1.0` requires signing, the remaining manual matrix, and a
  final release review. This dev build is not that release.
