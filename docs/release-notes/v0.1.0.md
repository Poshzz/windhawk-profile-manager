# v0.1.0 — Developer/Test Build

This is the first feature-complete build of Windhawk Profile Manager. It is a
developer/test artifact until the GUI and helper are code-signed.

## Included

- Mac Blur Glass theme pack with 10 Windhawk mods and a Default Windows reset
  profile.
- User profiles: create, edit, duplicate, delete, capture, JSON import/export.
- Snapshot-first apply with typed registry plans, typed verification, automatic
  rollback, journal recovery, and snapshot restore.
- `.reg` snapshot import/export plus metadata JSON export.
- Thai/English UI, light/dark/system themes, reduced-motion and keyboard support.
- Settings, snapshot retention, diagnostics, redacted rotating logs, and first-run
  onboarding.
- Per-machine NSIS installer for Windows 11 x64 with a fixed helper directory.

## Verification before publication

- [ ] Signed GUI/helper binaries.
- [ ] Installer built on a signed build or SAC-off VM.
- [ ] Manual matrix: apply Mac → reset → apply, UAC cancel, kill mid-run and
      recover, restore, missing mods, service stopped, Rainmeter/Explorer,
      Thai/English at 100%/125%/150%, install/uninstall.
- [ ] `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm test`,
      `npm run test:e2e`, `npm run package`, `npm run smoke:asar`,
      `npm run smoke:fuses`, `npm run smoke:packaged`.
- [ ] SHA-256 checksums published with the installer.

## Known limitations

- Unsigned builds can be blocked by SmartScreen or Smart App Control.
- v1 is Windows 11 x64 only and requires the standard `C:\Windows`,
  `C:\ProgramData`, and `C:\Users\<name>\AppData\Local` layout; relocated system
  or user data roots fail closed. It does not support per-user Windhawk
  configuration, portable mode, or a non-HKLM Windhawk root for writes.
- Tray, hotkeys, auto-start, auto-update, and silent scheduling are intentionally
  out of scope for v1.
