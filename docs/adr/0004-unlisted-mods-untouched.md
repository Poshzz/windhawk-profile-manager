# Leave unlisted mods untouched by default

A profile manages only the mods it lists. Installed mods outside the profile keep their state, so switching themes cannot disable a mod the user relies on. Each profile has an opt-in "disable all other mods" switch for users who want authoritative switching.

The pre-apply plan always shows the unlisted mods, so the choice is visible before anything changes. The original `.bat` kit behaved authoritatively; this is a deliberate departure.
